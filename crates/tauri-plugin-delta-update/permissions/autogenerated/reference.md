## Default Permission

Default permissions for the delta-update plugin

#### This default permission set includes the following:

- `allow-check`
- `allow-prepare`
- `allow-cancel-prepare`
- `allow-status`
- `allow-confirm-healthy`
- `allow-restart-to-apply`
