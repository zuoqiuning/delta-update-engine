## 自查方法

1. 运行 `delta-update version`，或查看应用中 `tauri-plugin-delta-update` 的版本。
2. 对照上表的“影响版本”与“修复版本”；`0.x` 版本按 SemVer 处理，预发布版本视为低于同版本正式版。
3. 命中影响范围时升级到修复版本；无法立即升级时按 advisory 中的缓解措施处理。

## 维护者流程

公开 advisory 后，在同一 PR 中追加一行：advisory 链接、CVE（如有）、受影响区间、修复版本、一句话摘要。未修复前不要提前填写修复版本或细节。
